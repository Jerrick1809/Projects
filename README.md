# Projects
All my projects that I have worked on since the start (Ranging from 2023 onwards)

1. 3D Component Detection & Virtual Installation System (Internship at Nanyang Polytechnic)

Context & Objective: Operated an Artec Leo 3D scanner and processed point cloud data to automate quality assurance and virtual installation alignment (VP Inspect) for Activefire water sprinkler DfMA (Design for Manufacturing and Assembly) systems.
   
2. Real-Time Facial Detection & Recognition System (EE4228 Intelligent System Design)

Context & Objective: Built a two-stage real-time facial recognition desktop application capable of registering new users live, extracting embeddings, and identifying known subjects vs. rejecting strangers as "Unknown" on standard CPU hardware.
   
3. Product Review Sentiment Analysis with BERT (IE4483 Artificial Intelligence & Data Mining)

Context & Objective: Developed a binary NLP sentiment classifier on 7,401 product reviews to distinguish positive (1) and negative (0) customer feedback.
  
4. AI-Driven Stock Market Forecasting & Analytics Platform (EE3180 Design & Innovation Project)

Context & Objective: Engineered an end-to-end multi-page Streamlit web platform combining historical price forecasting, financial news sentiment analysis, and technical indicators to generate data-driven Buy/Sell/Hold signals.
   
5. Fraudulent Job Listing Classification (IE0005 Intro to Data Science & AI)

Context & Objective: Built a machine learning pipeline in Python (NumPy, Pandas, Seaborn, Scikit-Learn) to classify real vs. fraudulent job postings from a 17-variable Kaggle dataset
